# Personal Shopping Assistant

A prototype e-commerce platform featuring an AI-powered shopping assistant that helps users find products through natural language conversations.

## Overview

The shopping assistant uses semantic search and vector embeddings to understand user queries and provide personalized product recommendations based on conversational context.

## Tech Stack

- **Frontend & Backend**: Next.js
- **Database**: PostgreSQL with Prisma ORM
- **AI & Search**:
  - OpenAI API for natural language processing
  - pgvector for vector embeddings
  - Semantic search with RAG
  - Token optimization for efficient API usage
- **Deployment**: Vercel

## Features

- Browse products by category
- AI-powered shopping assistant with conversational interface
- Semantic search using vector embeddings
- Real-time chat functionality
- Responsive design
